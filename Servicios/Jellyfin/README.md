🎬 Media Server & Automation Stack

Este repositorio contiene la configuración para desplegar un centro multimedia completo y automatizado. Utiliza Jellyfin para la reproducción de contenido y el ecosistema "Servarr" para automatizar la búsqueda, descarga y organización.

📦 Servicios Incluidos

Jellyfin: Servidor de streaming multimedia (películas, series, música).

Sonarr: Gestor de descargas de series.

Radarr: Gestor de descargas de películas.

Bazarr: Descarga automática de subtítulos.

Prowlarr: Indexador global para conectar trackers con Sonarr/Radarr.

qBittorrent: Cliente torrent para las descargas.
